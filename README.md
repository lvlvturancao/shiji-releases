# 拾集 Shiji · Windows 版发布

这里只放 Windows 版的发布包，不提供源码。项目主页与安卓版在 https://shiji-2cw.pages.dev 。

## 下载

**拾集 Windows 版 v0.7.0**（约 109 MB，解压后单文件 `Shiji.exe`）

- 直接下载：https://github.com/lvlvturancao/shiji-releases/releases/download/v0.7.0/Shiji-win-0.7.0.zip
- SHA-256：`3d30551ec3d31fe20e075d3e2a8831de18505276fd58cf9d73c244ade46ae87e`

解压后双击 `Shiji.exe` 即可使用。单文件绿色版，不需要安装 Python 或任何依赖；首次启动稍慢属正常。

## 环境要求

Windows 10 / 11，64 位。

## 这个版本能下什么

- 网页图集：粘贴链接即可解析，支持自动翻页与懒加载图片。
- 网页视频：直链与分段流都能识别，分段流自动合并成 MP4。
- YouTube 等需要专门解析的视频站点。
- B 站视频、抖音作品（视频与图集）。
- 浏览器嗅探：由浏览器实际发出的请求里取媒体地址。
- 下载前预览筛选：按分辨率、文件大小、格式过滤。

## 首次运行被 Windows 拦截

程序未做代码签名，浏览器或 SmartScreen 可能提示「Windows 已保护你的电脑」。点「更多信息」→「仍要运行」即可。

## 更新

程序内「帮助 → 检查更新」会给出新版本与下载地址；本仓库的 [Releases 页面](https://github.com/lvlvturancao/shiji-releases/releases) 同步列出各历史版本。
