# 拾集 Shiji · Windows 版发布

拾集是一款本地优先的批量下载工具：粘贴网页链接，它把页面里的图片、图集和视频抓下来存到本机，下载前可以先预览勾选，也可以按尺寸、大小、格式过滤。支持 Android 与 Windows 两端。

- 项目主页 / 安卓版下载：https://shiji-2cw.pages.dev
- 本仓库只提供 Windows 版的安装包，不含源码。

## 怎么用

1. 下载上面的压缩包，解压到任意文件夹。
2. 双击 `Shiji.exe`。单文件绿色版，不需要安装，也不需要 Python 或其它依赖；首次启动稍慢属正常。
3. 把网页链接粘贴进地址栏，点下载。开了「下载前先预览」的话，会先列出抓到的资源让你勾选。
4. 下载结果默认存到系统的下载目录，可在设置里改。

## 环境要求

Windows 10 / 11，64 位。

## 能下什么

两端共有的能力：

- **网页图集**：粘贴链接即可解析，支持自动翻页与懒加载图片。
- **网页视频**：直链与分段流都能识别，分段流自动合并成 MP4。
- **B 站视频**、**抖音作品**（视频与图集）。
- **浏览器嗅探**：从浏览器实际发出的请求里取媒体地址，应对地址不在页面上的情况。
- **下载前预览筛选**：按分辨率、文件大小、格式过滤，避免抓到无关图。

只有 Windows 版有的：

- **YouTube 等需要专门解析的视频站点**。

只有安卓版有的：

- 内置浏览器（边看边下、书签、多标签、去广告）、本地图库浏览与管理、日夜间模式。
